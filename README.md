# Canal-anonimo_SOS
## Esse é um Projeto do Eniac onde o propósito é desenvolver uma solução que ofereça um canal seguro acessível e anônimo para que os colaboradores possam registrar reclamações, denúncias e sugestões relacionadas ao ambiente de trabalho. A proposta deve fortalecer a confiança entre a empresa e seus colaboradores

_____________________________________________________________________________________________________________________________________________________________________________________________________


# Principais Desafios
## - Garantir o anonimato
## - Ser de utilização e proporcionar um processo confiável para o acompanhamento das manifestações.


_____________________________________________________________________________________________________________________________________________________________________________________________________


# Método de Avaliação 
## - ele será avaliado pela segurança do canal, pela confiança dos colaboradores em utilizá-lo e pela contribuição para um ambiente de trabalho mais saudável e transparente.
